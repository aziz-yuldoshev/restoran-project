# 🍽️ RESTORAN PROJECT

A Django-based web project focused on restaurant-related functionality.

## 📌 About the Project

RESTORAN PROJECT is a web application developed with Python and Django. It is designed as a restaurant-themed project and can be extended with additional features depending on the implementation.

## 🛠️ Technologies

- Python
- Django
- HTML
- CSS
- SQLite (if configured in the project)

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/aziz-yuldoshev/restoran-project.git
   cd restoran-project
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

   Windows:

   ```bash
   venv\Scripts\activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

   If the project does not contain a `requirements.txt` file, install the dependencies used by the project.

4. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

5. Start the development server:

   ```bash
   python manage.py runserver
   ```

6. Open `http://127.0.0.1:8000/` in your browser.
